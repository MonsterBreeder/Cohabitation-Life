## 已实现（代码完成）

- 启动页拆分为"恢复中 / 恢复失败 / 普通欢迎 / 邀请摘要 / 邀请终态"五种视图
- 欢迎页主按钮"开始使用"，次按钮"先看看怎么用"，不出现"微信快捷登录"或"创建我的家"
- 协议勾选**内联在欢迎页**：仅 welcome / invite-summary 模式显示；未勾选时主按钮不可点；勾上后直接调云端分流
- 老用户清除本地标记后只需 1 次勾选 + 1 次点击进家（**2026-09-11 调整**：删除独立 start 页）
- 邀请摘要只展示邀请人昵称头像、家庭名、当前成员数；自定义头像经云端换取短时 https URL
- 邀请预览通过 token + 版本号作废迟到响应，切换邀请 / 失败 / 主动结束都不残留旧摘要
- 协议确认后由 `startUse()` 调云端，按真实状态路由到 home / create-home / join-home
- 用户协议 / 隐私政策拆为可独立访问的本地静态页面，结构与法条小节已就绪
- 邀请终态页只暴露受控提示，按 hasStartedUse / hasHousehold 决定唯一下一步
- 体验页纯状态（事项认领 / 临时记账 / 足迹展开）只写在内存，离开 / 重入即重置
- 体验金额规则直接复用 `validateAmountCents`，不写第二套
- 占位示例图已生成在 `src/static/experience/footprint-sample.png`（约 3KB）
- 旧登录计划中的本地标记（`auth.login.completed`）保留，向上兼容已上线用户
- ce-code-review 修复：start 页 create / unavailable 路径提交前清掉邀请的逻辑已并入欢迎页（startUse 前按上下文决定）

## 安全 / 边界复核清单

- [x] 启动 / 回前台不会在没有用户动作前创建 `users` 记录
- [x] 邀请预览只读，不消费邀请，不修改邀请状态
- [x] 协议确认后由 `resolve-login` 重新核验，预览结果不作为加入依据
- [x] 自定义头像响应只含受控编号或短时 https URL，无存储路径 / 资源编号 / digest
- [x] 邀请摘要文案、错误信息、调试输出均不包含邀请原文或家庭编号
- [x] 体验页不导入业务 store 或云端服务
- [x] 协议页和邀请状态页只读本地状态，不写 Pinia / 本地存储 / 云端
- [x] 主包/分包体积在加入示例图后仍有余量
