# 家里有事品牌视觉标准

更新日期：2026-08-13
状态：已确认

## 品牌气质

年轻、可爱、亲密、轻松。表达情侣共同生活和平等协作，不使用监督、家政或社区服务的视觉语言。

## Logo

正式 Logo 为“双人小团子”：一绿一珊瑚的两个小团子靠在一起，上方是简化屋檐，右侧小勾表示一起完成生活小事。

- 素材位置：`src/static/brand/logo.png`
- Logo 周围应保留充足空白，不紧贴文字和页面边缘。
- 小程序图标使用完整方形版本。
- 页面内展示时不得拉伸、变色、旋转或增加文字。

## 标准颜色

| 用途 | 颜色 | 使用位置 |
| --- | --- | --- |
| 品牌主色 | `#43C89A` | Logo、选中状态、装饰图形 |
| 主要操作色 | `#267A5A` | 主要按钮和需要白字的区域 |
| 情侣搭配色 | `#FF8F79` | 少量重点、温和提醒、品牌插图 |
| 页面背景 | `#FFF9F2` | 页面大背景 |
| 卡片背景 | `#FFFFFF` | 表单、卡片和内容区 |
| 主要文字 | `#29443A` | 标题和正文 |
| 次要文字 | `#74847D` | 辅助说明 |
| 浅色边框 | `#E4ECE7` | 输入框和卡片边界 |

## 使用比例

- 奶油白和白色约占 70%。
- 绿色约占 20%。
- 蜜桃珊瑚不超过 10%。

## 圆角

- 主要按钮使用大圆角，呈现柔和、亲近的感觉。
- 卡片使用中等圆角。
- 输入框使用小一档圆角，并保持全项目一致。

## 禁止事项

- 不使用大面积蜜桃珊瑚，避免过分甜腻。
- 不用薄荷绿承载白色小字，避免看不清。
- 不添加传统爱心、人物拥抱、烟囱房屋等额外符号。
- 不使用强烈阴影、金属质感和复杂渐变。
