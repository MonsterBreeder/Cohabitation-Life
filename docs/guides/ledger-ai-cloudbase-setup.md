# “问账本”腾讯云资源准备与操作步骤

本指南用于在开发“问账本”前确认免费资格、资源余量和费用开关，并在代码完成后部署所需云资源。所有操作都使用当前小程序已经在用的微信云开发环境，不新建第二套环境，不购买模型资源包，不开启自动付费。

腾讯云控制台名称可能随版本调整。若页面名称与本文略有不同，以“云开发环境、套餐用量、AI 模型用量、云函数、数据库”这些入口为准。

截至 2026-08-31，本次准备已确认：成长计划资源已到账，赠送文本额度剩余 100%，云开发个人版有效期显示到 2027-02-28，按量付费和自动续费均已关闭。当前成长计划体验模型使用 `hy3`，不得再选控制台提示即将下线的 `hy3-preview`。这些结果只代表本次控制台状态，发布前仍需重新核对。

## 一、先确认能否免费试用

### 第 1 步：确认当前小程序使用的云环境

1. 打开微信开发者工具，进入当前小程序项目。
2. 点击顶部“云开发”。
3. 查看当前选中的环境名称和环境 ID。
4. 打开项目文件 `src/config/cloud.ts`，确认其中的环境 ID 与控制台当前环境一致。
5. 在该环境中确认能看到现有的 `ledger` 云函数以及 `ledgerEntries`、`ledgerCategories`、`ledgerOperations` 集合。
6. 如果不一致，先停止操作，不要创建新环境，也不要修改项目环境 ID。

完成标准：微信开发者工具、项目配置和云开发控制台显示的是同一个现有环境。

### 第 2 步：确认小程序绑定的腾讯云账号

1. 使用小程序管理员微信登录微信公众平台。
2. 在账号或第三方服务相关页面确认当前小程序绑定的腾讯云账号。
3. 再登录腾讯云控制台，确认账号信息中能看到该小程序的绑定关系。
4. 如果微信开发者工具打开的云环境不属于这个腾讯云账号，先停止报名成长计划，避免把一次性资格领到错误账号。

完成标准：小程序、腾讯云账号和第 1 步确认的云环境属于同一组绑定关系。

### 第 3 步：检查或报名“小程序成长计划”

1. 登录微信公众平台并选择当前小程序。
2. 进入“行业能力”。
3. 打开“小程序成长计划”。
4. 如果页面显示已经参加，记录参与状态、绑定环境和资源有效期，不要重复操作。
5. 如果尚未参加，先阅读页面显示的活动规则，再点击报名。
6. 报名时选择第 1 步确认的现有微信云开发环境，不能选择其他环境。
7. 提交前再次核对环境 ID；一个小程序账号只能参加一次，领取后不能随意切换腾讯云账号或云开发环境。
8. 等待页面显示报名成功或资源发放成功。

完成标准：当前环境获得可用的 AI 资源包，或者页面明确显示已有可用权益。

如果页面没有报名入口、不符合资格或无法选择当前环境：停止“问账本”上线准备，不购买 Token 资源包，原账本继续正常使用。

官方说明：<https://docs.cloudbase.net/ai/ai-inspire-plan>

### 第 4 步：确认 AI 模型额度

1. 打开当前环境的云开发控制台。
2. 进入“AI 模型用量”或“AI+”相关页面。
3. 查看文本模型资源包是否已经到账。
4. 记录可用模型、剩余 Token 和到期时间。
5. 确认资源包允许从微信小程序或云函数调用。
6. 不手动购买 Token 资源包，不填写第三方模型密钥，不启用自定义付费模型。
7. 后续开发只选择控制台当时实际可用的体验模型，不在小程序前端写死模型名称。

完成标准：控制台能看到可用的文本模型、正数余额和未过期日期。

如果余额为 0、资源已过期或没有可用体验模型：保持“问账本”关闭。

官方说明：<https://docs.cloudbase.net/ai/model/overview>

### 第 5 步：检查云开发基础资源

1. 在同一云开发环境中打开“套餐用量”或“资源用量”。
2. 查看当前套餐名称、到期时间和剩余资源点或基础配额。
3. 重点查看云函数调用、云函数运行时间、数据库读写、数据库容量和日志相关用量。
4. 如果成长计划发放的是代金券，到腾讯云“费用中心 → 优惠管理 → 代金券”查看金额和有效期。
5. 保存当前用量截图，作为开发前基线；截图不要上传到版本库。

完成标准：基础环境仍有足够余量和有效期，普通记账当前可以正常调用云函数和数据库。

### 第 6 步：关闭自动付费并确认风险

1. 在当前环境的“套餐管理”“环境设置”或“用量管理”中寻找“超限按量”“超额按量”或类似开关。
2. 确认该开关处于关闭状态。
3. 确认没有开启套餐自动升级、自动购买模型资源包或其他自动扣费能力。
4. 如果控制台没有显示该开关，不要通过不熟悉的接口盲目修改；先从腾讯云费用中心和云开发环境订单确认是否存在按量计费，再联系腾讯云客服核实。
5. 关注云开发和微信公众平台发送的 80%、90%、100% 用量提醒。

必须理解：关闭超限按量可以避免超额自动计费，但基础资源耗尽时可能导致整个云开发环境停服，普通记账也可能暂时不可用。免费、不自动付费和绝对不停服无法同时保证。

官方说明：<https://docs.cloudbase.net/solutions/cloudbase-for-platforms/quota>

### 第 7 步：作出是否继续开发的决定

以下条件必须全部满足：

- 当前小程序、腾讯云账号和云环境绑定一致。
- 当前环境拥有可用且未过期的 AI 文本资源包。
- 基础云开发套餐仍有效且有足够余量。
- 超限按量和自动购买能力已经关闭。
- 接受“基础资源耗尽时整个环境可能停服”的限制。

任一条件不满足：暂停“问账本”，不购买付费资源，也不影响现有功能继续维护。

## 二、代码完成后部署云资源

以下步骤要等 `cloudfunctions/ledger-ai/` 和对应前端代码开发、测试通过后再操作。

### 第 8 步：创建问答集合

1. 打开云开发控制台的“数据库”。
2. 新建集合 `ledgerAiDailyUsage`。
3. 新建集合 `ledgerAiSessions`。
4. 将两个集合的安全规则都设为“所有用户不可读写”，只允许云函数访问。
5. 不要选择“所有用户可读”“仅创建者可读写”等客户端规则。
6. 为 `ledgerAiSessions.expiresAt` 建立升序索引，供每日清理过期会话；`ledgerAiDailyUsage` 按固定记录编号读写，第一版不需要额外索引。

完成标准：小程序客户端直接读取或写入两个集合都会得到权限错误，云函数可以正常访问。

### 第 9 步：部署 `ledger-ai` 云函数

1. 在微信开发者工具的云函数目录中找到 `ledger-ai`。
2. 选择“上传并部署：云端安装依赖”。
3. 等待部署成功，确认没有依赖安装错误。
4. 在云函数配置中设置适合模型请求的超时时间，具体值以测试结果为准。
5. 确认函数使用当前环境，不配置腾讯云永久密钥，不把任何模型密钥写入代码或文档。
6. 保持“问账本”云端功能开关关闭。
7. 在云函数环境变量中设置 `LEDGER_AI_MODEL=hy3`、`LEDGER_AI_ENABLED=false`；不设置任何密钥。

完成标准：测试调用能完成身份检查和状态查询，但正式用户入口仍未开放。

云函数说明：<https://docs.cloudbase.net/cloud-function/manage>

### 第 10 步：配置临时记录清理

1. 先确认当前数据库是否支持按过期时间自动删除记录。
2. 如果支持，为 `ledgerAiSessions` 配置自动过期：闲置 30 分钟不可继续使用，创建后最长保留 2 小时。
3. 本项目已经提供 `cloudfunctions/cleanup-ledger-ai-requests/`，选择“上传并部署：云端安装依赖”，其定时触发器每天 03:20 清理到期记录。
4. 清理任务只能处理 `ledgerAiSessions`，不能扫描或删除普通账目。

完成标准：过期会话不可继续追问或查看全部，普通账目没有任何变化。

### 第 11 步：完成测试环境验证

1. 使用固定测试账目验证模糊找账、简单金额计算和趋势跳转。
2. 使用两个真实家庭成员账号验证每天共享 10 次。
3. 使用第三个非家庭账号验证无法读取账目和候选结果。
4. 验证“第一笔”追问只能引用当前用户当前会话的候选。
5. 修改或删除候选账目后再次追问，确认不会返回旧内容。
6. 模拟模型额度耗尽，确认只关闭问账本。
7. 检查云函数日志和 AI 日志，确认没有问题正文、回答正文、账目备注和内部编号。
8. 查看一次问答前后的 AI Token、云函数和数据库用量变化，估算每天最多 10 次的真实消耗。

完成标准：安全、额度、隐私和失败状态全部通过；任何一项失败都不开放入口。

### 第 12 步：小范围开启并持续观察

1. 确认所有检查通过后，再打开云端“问账本”功能开关。
   - 在 `ledger-ai` 云函数环境变量中把 `LEDGER_AI_ENABLED` 从 `false` 改为 `true`，无需重新上传小程序。
2. 只对少量真实账号试用。
3. 每周查看“AI 模型用量”和“套餐用量”。
4. 余量不足、资源即将过期、模型不可用或日志不符合隐私要求时，立即关闭问账本。
5. 关闭问账本后，再次确认记账、筛选、统计和详情仍可正常使用。

## 三、最终需要的资源

| 资源 | 数量 | 说明 |
| --- | --- | --- |
| 现有微信云开发环境 | 1 | 继续复用，不新建 |
| AI 文本资源包 | 1 份可用权益 | 成长计划或控制台当前免费权益 |
| `ledger-ai` 普通云函数 | 1 | 新增 |
| `ledgerAiDailyUsage` 集合 | 1 | 新增 |
| `ledgerAiSessions` 集合 | 1 | 新增 |
| 临时记录清理任务 | 1 | `cleanup-ledger-ai-requests` 每天清理过期记录 |
| 向量数据库 | 0 | 第一版不需要 |
| 云服务器 | 0 | 不需要 |
| 第三方模型密钥 | 0 | 不需要 |

## 四、不要做的操作

- 不要为了领取成长计划新建第二个云环境。
- 不要把成长计划领取到不属于当前小程序的腾讯云账号。
- 不要开启超限按量后忘记关闭。
- 不要购买 Token 资源包或接入第三方付费模型。
- 不要把 AppSecret、腾讯云密钥或模型密钥写入项目。
- 不要在开发完成前打开正式入口。
- 不要把控制台截图、环境订单或账号信息提交到版本库。
