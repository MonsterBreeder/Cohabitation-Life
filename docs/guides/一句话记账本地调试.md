# 一句话记账本地调试

本功能对应PRD020。先构建小程序，在微信开发者工具打开本独立目录，为ledger打开云函数本地调试。需要本机ai-center单独的应用服务，云端固定配置本机连接地址、独立应用凭据和另一份草稿签名密钥。配置值只放受保护的服务环境，不在页面或文档填写真实值。

本轮不部署或启动定时清理。真实模型代表检查已按单独批准范围完成，累计17/24次，原失败保留；不自动再用剩余次数。详细配置项和限制见ai-center的 `docs/guides/mulu-bookkeeping-local.md`。工具本地调试开关和微信真实身份已经实际核对，本机受控检查不能替代。

首次发送前页面说明会将本次输入及必要的类目成员显示信息交给模型整理；不同意不发送。原话、补问和清单在本页内存，退出清空，不写个人长期记忆。保存回执只留逐项状态和成功引用30天，不恢复失败清单。第三方处理及日志范围单独核实，不承诺可删除第三方留存。
