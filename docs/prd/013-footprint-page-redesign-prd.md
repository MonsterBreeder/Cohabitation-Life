# PRD 013：足迹页视觉重设计

日期：2026-09-07
状态：已实现，待微信开发者工具视觉确认

## 目标

在不改变足迹业务规则的前提下，重新整理足迹页的视觉层级，让地图成为页面主角，让新增、浏览和导航三个操作更容易理解，并保持睦录年轻、亲密、轻松的品牌气质。

## 页面要求

- 顶部以轻量旅行手账感展示“我们的足迹”和累计地点数，“新增足迹”仍是最主要操作。
- “地图 / 列表”切换紧贴对应内容，不与顶部统计抢层级。
- “选地点导航”使用独立功能区，明确说明导航不会保存足迹。
- 地图放入清晰的地图区域，空数据时地图继续显示，引导信息只能位于地图下方。
- 列表空状态缩短，首屏不出现大面积无意义空白；已有记录的列表和地点卡片保持可读。
- 使用现有品牌颜色、圆角和 Wot UI，不引入新字体、外部图片或新设计体系。
- 页面适配当前小程序窄屏，底部内容不得被导航栏遮挡。
- 保留加载、失败、权限拒绝和重复点击保护，不改变任何云端数据逻辑。

## 验收标准

- 地图与列表模式的信息层级清晰，核心操作无需滚动即可看见。
- 零足迹时地图仍完整显示，地图下方能新增第一条足迹。
- 地图、列表、导航、新增、地点详情入口与改版前行为一致。
- 自动检查、微信小程序构建和包体积检查通过；实际页面截图无明显遮挡、溢出或文字挤压。
