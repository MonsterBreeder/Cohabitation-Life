# PRD 002：品牌主色与 Logo

更新日期：2026-08-13
状态：已确认

## 目标

建立一套年轻、温和、有生活感的视觉方向，让“家里有事”看起来像两个人共同生活的轻量工具，而不是家政、社区或监督管理产品。

## 品牌感觉

- 年轻、轻松、亲密但不过分甜腻。
- 强调平等协作，不强调任务压力。
- 简洁、有辨识度，适合微信小程序图标。

## 已确认主色调

| 用途 | 名称 | 颜色 |
| --- | --- | --- |
| 主色 | 薄荷绿 | `#43C89A` |
| 主要操作色 | 深薄荷绿 | `#267A5A` |
| 搭配色 | 蜜桃珊瑚 | `#FF8F79` |
| 页面背景 | 奶油白 | `#FFF9F2` |
| 主要文字 | 深绿灰 | `#29443A` |
| 次要文字 | 柔和灰绿 | `#74847D` |

薄荷绿代表轻松、清爽和共同成长，用于 Logo、选中状态和主要品牌图形。蜜桃珊瑚表达亲密与温度，用于搭配图形、少量重点和温和提醒，不作为大面积页面底色。奶油白取代纯白，让页面看起来更柔和、更有生活感。

深薄荷绿用于主要按钮。薄荷绿直接搭配白色文字不够清楚，因此不用于大面积的白字按钮。

### 使用比例

- 奶油白与其他浅色背景约占 70%。
- 薄荷绿约占 20%，用于主要操作和品牌识别。
- 蜜桃珊瑚不超过 10%，避免页面显得甜腻或像儿童产品。

### 按钮规则

- 主要按钮：深薄荷绿 `#267A5A` 底、白色文字。
- 次要按钮：奶油白底、薄荷绿文字和边框。
- 危险或不可逆操作不使用蜜桃珊瑚，应单独使用明确的警示颜色。

## 已确认 Logo

- 采用 A 版“双人小团子”图形。
- 一绿一珊瑚的两个小团子靠在一起，表达情侣共同生活和平等陪伴。
- 上方的简化屋檐表示共同的家，小勾表示一起完成生活小事。
- 图标不放“家里有事”文字，保证缩小后仍然清楚。
- 正式素材路径：`src/static/brand/logo.png`。

## 禁止方向

- 家政、物业、社区服务感。
- 过度甜腻的情侣图案。
- 排名、打卡、监督和警告感。
- 复杂渐变、立体阴影和过多细节。

## 已确认结果

- Logo：A 版“双人小团子”。
- 主色：薄荷绿 `#43C89A`。
- 主要操作色：深薄荷绿 `#267A5A`。
- 搭配色：蜜桃珊瑚 `#FF8F79`。
- 背景色：奶油白 `#FFF9F2`。
