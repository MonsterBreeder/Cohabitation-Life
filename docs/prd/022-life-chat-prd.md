# PRD 022 睦录聊天助手

## 入口

账本、首页事项区和足迹页各有一个对应业务的聊天入口。原「问账本」和「一句话记账」在切换后都进入账本聊天。各页面的入口限定在本业务。右下角聊天图标在手动「＋」上方，点一下直接进统一聊天。从聊天返回继续原页的筛选和浏览。展开「＋」菜单、开启当前页弹窗或进入填写页时收起聊天图标。

## 聊天能做什么

| 业务 | 操作 |
| --- | --- |
| 账本 | 找账、合计、比较、逐笔查看依据。继续支持一次记多笔。每张修改卡核对一笔原记账人有权管理的旧账。删除在账目详情完成。 |
| 事项 | 新增、修改和删除首页的共同事项。缺名称或类型时先问。已结束的事项按现有规则查看。 |
| 足迹 | 新增、修改和删除去过的地点。输入地名后核对实际地点，同名时先选。没说游玩日期时显示今天，可在确认前修改。照片在原表单管理。 |

助手依据当前问题和当前聊天补问。示例只填入输入框。遇到多条相似记录时先选目标。一句话包含多个栏目时先选一个操作，余项可在同一聊天里继续处理。查账直接展示结果，基于原账目计算，来源可点开。新增、修改和删除由用户点击最新卡片确认。卡片显示具体记录、修改差异或删除影响。记录已经变化时请用户重新核对。只有实际保存成功才显示成功，断网先查回原操作的结果。

## 数据用途与验收

首次发送前解释模型处理的数据用途。聊天和未确认内容退出后清空，切换家庭立即作废旧内容。只处理本人有权访问的家庭，不发送凭证、足迹照片或无关记录。原表单、筛选、统计继续可用。已有用量和线上配置在切换前核对，新的调用额度届时单独确认。

在账本、事项和足迹实际核对保存结果。验证成员权限、旧卡片、同时修改、重复提交、断网查回、拒绝数据用途与额度用尽。微信开发者工具、双账号和手机结果分别登记。界面草图已确认，当前按本机实施范围推进。

11 月 18 日用户明确要求本轮跳过双账号和手机实测，两项按跳过登记。本轮交付以已有页面操作、模拟器记录、真实模型和当前家庭实际保存结果为依据。联网预览仅对已指定的当前家庭开放，批准的额外 6 次测试额度已经用完。
