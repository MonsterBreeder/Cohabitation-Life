# PRD 010：“问账本”RAG 问答

## 问题与目标

家庭账本已经支持按月份、具体日期、付款人、收支类型和类目筛选，也能查看月度统计。但当用户只记得大概金额、用途、时间或备注线索时，仍很难从历史记录中找回目标账目。

本期增加“问账本”：家庭成员可以用日常语言模糊找账，并完成有明确范围的简单金额汇总或比较。系统从当前家庭的真实账目中取得依据后再回答，并把候选账目和匹配原因展示出来供用户核对。

本期不把它做成通用聊天、趋势分析或理财助手。多月份趋势继续由现有统计页承担；输入方式可以开放，但回答范围必须受账本事实约束。

## 核心规则

1. 账本首页顶部提供“问账本”入口，点击进入独立页面，不替代现有筛选和统计。
2. 第一版以模糊找账为核心，同时支持按明确条件计算一个总额，或比较两个明确时间范围或两名成员的总额。
3. 第一版只读取金额、日期、付款人、收入或支出、类目和文字备注，不读取凭证图片。
4. 默认查询当前家庭全部未删除账目，不受进入页面前所选月份和筛选条件影响。
5. 找账回答先说明找到一笔还是多笔候选，再按“第 1 笔”到“第 5 笔”展示候选账目和简短匹配原因；超过 5 条时提供“查看全部”。
6. 金额由真实账目直接计算，模型只负责理解问题和组织表达，不能自行心算或修改计算结果。
7. 日期范围和收入或支出类型必须准确；金额、类目和备注可以适度模糊。只有日期等单一弱线索时不展示牵强候选。
8. 没有足够依据时明确说明“账本里没有足够记录”，建议补充金额、用途或大概月份；不使用常识补充，不猜测消费原因，不编造账目。
9. 页面采用连续聊天形式，支持补充线索和使用“第一笔”“第二笔”引用上一轮候选；退出页面后结束会话，不保存跨页面或跨天的问答历史。
10. 两名家庭成员共享家庭账目和每日额度，但各自的提问过程互不可见。
11. 每个家庭每天最多提问 10 次，连续追问也计为一次；正常答案和“没有足够记录”都计数。
12. 空白、过长、明显不属于账本或多月份趋势问题不计数；趋势问题提供“查看统计”入口。模型或云端网络调用未完成时不扣次数。若云端已经完成回答、仅手机未收到响应，相同提交重试返回原结果并仍只计一次。
13. 优先使用云开发模型体验额度。额度耗尽后停止问答，不自动购买资源或开启付费，不影响原有账本功能。

## 页面与交互

### 1. 账本首页入口

- “问账本”入口位于账本首页顶部。
- 点击后进入独立问答页面。
- 入口不改变当前月份、日期、付款人、收支类型和类目筛选。

### 2. 问答页初始状态

- 显示功能说明：“帮你从家庭账本中找到记不清的账目，也能做简单金额计算”。
- 显示当天剩余次数。
- 显示可填入输入框的示例问题，示例本身不能直接提交，避免误消耗次数。
- 首次使用前明确说明：回答时会把与问题相关的账目信息发送给云端模型；不同意时可以退出，不影响账本其他功能。

示例问题：

- “去年买电饭煲是哪一笔？”
- “帮我找两百元左右的火锅消费。”
- “上个月餐饮花了多少？”

### 3. 回答状态

- 提交后显示正在回答状态，并阻止重复提交。
- 正常找账回答说明找到一笔还是多笔候选，并显示最多 5 条候选账目。
- 每条候选显示真实日期、金额、类目、付款人、备注和简短匹配原因，不显示匹配百分比。
- 候选使用当前回答内稳定的顺序编号，点击可进入原账目详情；用户可以继续追问“第一笔”。
- 金额回答显示结论、时间范围和统计口径。
- 相关账目超过 5 条时显示“查看全部”。
- 连续追问必须重新核对当前账目，不能把上一轮回答当成新的事实来源。
- 被引用的候选已经删除或发生变化时，说明记录已经变化，不能继续把旧内容当作当前事实。

### 4. 无依据与失败状态

- 找不到足够依据时显示“账本里没有足够记录”，并建议用户换一种问法。
- 只有日期等单一弱线索时不展示无关候选，提示补充金额、用途或大概月份。
- 用户询问多月份趋势时，说明应使用统计页，并提供“查看统计”按钮；不自动跳转，也不消耗次数。
- 网络或模型服务失败时保留用户输入，允许重试，不扣次数。
- 当天次数用完时仍可进入页面和查看说明，但不能继续提交，并提示次日恢复。
- 平台体验额度耗尽时说明问答暂不可用，不能引导用户付费，也不能影响记账、筛选和统计。

## 可回答与不可回答示例

| 用户问题 | 是否回答 | 处理方式 |
| --- | --- | --- |
| 去年买电饭煲是哪一笔？ | 有依据时回答 | 根据时间、类目和备注展示最多 5 条候选及匹配原因 |
| 帮我找两百元左右的火锅消费 | 有依据时回答 | 日期和收支类型保持准确，金额与备注允许适度模糊 |
| 上个月餐饮花了多少？ | 是 | 返回金额、时间范围和相关餐饮账目 |
| 今年我和对方谁记的支出更多？ | 是 | 分成员计算并展示对比依据 |
| 最近三个月居家支出有什么变化？ | 不在问答中分析 | 不消耗次数，提供“查看统计”入口 |
| 为什么这个月花多了？ | 否 | 不分析原因，提示可查看统计页核对变化 |
| 帮我制定下个月投资计划 | 否 | 说明不提供投资或理财建议 |
| 我们谁花钱更合理？ | 否 | 不评价家庭成员，不做关系判断 |
| 凭证图片上写了什么？ | 否 | 第一版不读取凭证图片 |

## 次数规则

| 情况 | 是否扣除 1 次 |
| --- | --- |
| 正常返回答案 | 是 |
| 返回“没有足够记录” | 是 |
| 当前页面内连续追问 | 是 |
| 空白、过长或明显越界的问题 | 否 |
| 多月份趋势问题 | 否，提供“查看统计”入口 |
| 模型服务失败、超时或云端网络调用未完成 | 否 |
| 云端已完成回答、仅手机未收到响应 | 重试返回原结果，只计一次 |
| 重复点击同一次提交 | 只计一次 |

每天按北京时间自然日重置。两名家庭成员同时提交时，家庭总次数仍不能超过 10 次。

## 数据与隐私

- 用户身份和家庭归属必须由云端按当前微信身份确认，前端传来的家庭编号或成员身份不能作为可信依据。
- 每次只向模型提供完成当前回答所需的最少账目，不发送凭证图片、内部编号或无关账目。
- 账目备注和用户问题只能作为待处理内容，不能改变身份校验、读取范围、次数限制或“不允许猜测”等规则。
- 模型访问凭据只能保存在云端安全配置中，不得写入小程序、文档或版本库。
- 应用主动写入的业务日志不得包含问题正文、回答正文或家庭账目内容。
- 为限制次数保存的信息只能包含家庭、日期和次数，不记录用户问了什么。
- 为连续追问和断网重试临时保留的信息只能用于当前会话并自动失效，退出后不能重新打开为聊天历史。
- 发布前必须确认平台自身日志是否会记录问题或家庭账目，并据此更新隐私说明。

## 验收标准

1. 从账本首页顶部可以进入独立问答页，返回后原账本筛选条件不变。
2. “去年买电饭煲是哪一笔”等模糊问题能在最多 5 条候选中找到目标，并看到每条候选的匹配原因。
3. 日期和收支类型不会被放宽；金额、类目和备注可以适度模糊，实际账目内容不会被改写成用户描述。
4. 存在多笔相似结果时不会断言其中一笔就是目标；用户可以追问“第一笔”，且系统会重新核对该账目。
5. “上个月餐饮花了多少”等问题得到准确金额、明确时间范围和可点击的相关账目。
6. 回答最多先展示 5 条候选或参与计算的账目，“查看全部”包含全部实际匹配或参与计算的账目。
7. 多月份趋势问题提供“查看统计”入口，不生成趋势回答，也不消耗次数。
8. 无依据问题不会得到猜测性回答；理财、关系评价和凭证图片问题会被拒绝。
9. 两名成员共享每天 10 次限制，并发提交不会超过上限或重复扣减。
10. 退出问答页再进入时，不显示上一次的提问和回答。
11. 模型失败、网络失败或体验额度耗尽时，原账本仍能正常记账、筛选、统计和查看详情。
12. 非家庭成员无法读取任何账目或问答结果，返回内容不包含内部编号。
13. 用户拒绝首次数据用途说明后，不发送账目、不扣次数、不影响账本其他功能。

## 范围边界

- 不读取或识别凭证图片。
- 不提供预算、消费评价、理财或投资建议。
- 不在问答页提供多月份趋势、原因分析、预测或建议；趋势需求继续使用现有统计页。
- 不评价两名成员谁“花得合理”。
- 不保存长期聊天记录。
- 不支持语音提问。
- 不替代现有筛选和统计。
- 不保证体验额度永久存在；模型与额度规则以云开发控制台当时显示为准。
- 不在本期接入其他模型厂商或付费工具。

## 发布前置条件

- 在云开发控制台确认当前环境可用的内置模型、体验额度、有效期和额度耗尽后的返回状态。
- 关闭任何可能自动产生费用的选项，确认额度耗尽后只会停止问答。
- 确认平台日志与数据处理方式符合本 PRD 的隐私要求，并更新小程序隐私说明。
- 使用固定账目样本验证金额、日期、付款人、类目、无依据拒绝和连续追问。

## 腾讯云资源与费用边界

### 必需资源

| 资源 | 使用方式 | 是否新增 |
| --- | --- | --- |
| 微信云开发环境 | 继续承载身份、数据库、云函数和日志 | 复用现有环境 |
| 云开发 AI+ 模型额度 | 理解自然语言并根据检索结果组织回答 | 需要在现有环境中确认或领取 |
| `ledger-ai` 普通云函数 | 完成身份检查、找账、计算、次数限制和模型调用 | 新增 1 个 |
| 云数据库 | 读取现有账目，并保存家庭每日次数和临时会话 | 复用数据库，新增少量集合 |
| 日志与用量监控 | 查看失败、耗时和资源余量，不记录问题及账目正文 | 复用现有能力 |
| 临时记录清理 | 删除已经失效的短时会话 | 优先使用自动过期；不支持时新增清理任务 |

第一版不需要向量数据库、云服务器、新的文件存储或第三方付费 RAG 平台。

### 免费条件

- 免费模型资源不是永久权益。当前“小程序成长计划”需要单独报名，资源通常有有效期，并且一个小程序账号只能参加一次；最终资格、模型和剩余额度以当前小程序绑定环境的控制台为准。
- 只有同时具备可用的 AI 资源包和足够的云开发基础资源时，问账本才可以在不额外付费的情况下运行。
- 如果没有成长计划资格、AI 资源包已经过期或控制台没有可用体验模型，本期停止上线，不自动购买 Token 资源包，也不接入其他付费模型。

### 基础资源风险

- AI Token 耗尽与云开发环境基础资源耗尽是两种不同情况。AI Token 耗尽时可以只关闭问账本。
- 云函数、数据库等基础资源与原账本共用同一个云开发环境。若基础套餐或资源点耗尽且关闭超限按量，整个环境可能停服，普通记账也可能受到影响。
- 本项目优先遵守“不自动付费”，因此保持超限按量关闭，并通过家庭每天 10 次、功能开关、用量提醒和提前停用问答降低风险；不能承诺基础环境资源耗尽时原账本仍绝对不受影响。
- 发布前必须按照 `docs/guides/ledger-ai-cloudbase-setup.md` 完成资源确认。任一免费条件不满足时，问账本保持关闭。

## 后续评估

本功能先小范围试用。只记录提问次数、成功次数、无依据次数和失败次数，不记录问题正文。若实际问题大多能由现有筛选完成，或无依据比例过高，则不继续扩大范围。
