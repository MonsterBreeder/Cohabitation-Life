# PRD 012：足迹地点导航

日期：2026-09-03。需求依据：用户明确要求“先增加导航功能”，取消本次自动到达记录。

## 目标与范围

用户可以选择尚未去过的目的地，或从已有足迹出发打开微信地图，再由地图提供路线导航。不自建导航、不接入高德密钥，不新增后台定位、到达判断或行程记录。

## 页面规则

- 足迹页增加“选地点导航”，地图和列表模式均可使用，零足迹也可使用。选中地点后打开微信地图，不需要先保存足迹。
- 地图中选中已有地点后，在地点卡片提供“导航去这里”；足迹详情也提供同样入口，目的地取自当前所见地点。
- 用户进入微信地图后自行选择路线或可用导航方式；不承诺固定使用高德，也不把打开地图视为到达。
- 只有点击按钮才开始选择或打开地点；不在进入页面时获取当前位置，不跟踪行踪。
- 打开期间阻止重复点击；取消不报错，失败保留页面并说明可以重试。地点数据无效时不能导航到默认坐标。
- 不创建、修改或删除足迹；导航返回后现有足迹数量、日期、照片和回忆保持不变。

## 验收与执行清单

- [x] 无足迹时也能选择目的地导航，且不创建足迹。
- [x] 已有地点卡片与详情的导航目的地一致，名称、地址、坐标正确。
- [x] 取消、失败、无效地点、连续点击均有正确处理，失败后可重试。
- [x] 页面加载不申请定位；导航过程中没有足迹写入和后台定位。
- [ ] 自动检查已通过；当前自动化环境无法读取微信开发者工具窗口，页面布局和手机地图跳转仍需真机确认。

## 与已有需求的关系

本需求仅扩展 PRD 011 的导航范围边界，其余共同足迹规则保持不变。导航是独立操作，不要求先把目的地保存为去过的地方。
