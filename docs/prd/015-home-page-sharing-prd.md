# PRD 015 首页微信转发与朋友圈分享

状态：已确认

## 问题与目标

用户在首页打开微信右上角菜单时，“转发”和“分享到朋友圈”均不可用，无法把睦录推荐给微信好友或朋友圈。

本需求恢复首页的两种微信分享入口，并提供统一、克制的品牌文案。

## 需求

- R1. 首页右上角菜单中的“转发”必须可用。
- R2. 首页右上角菜单中的“分享到朋友圈”必须可用。
- R3. 转发卡片标题使用“睦录｜把共同生活认真记下来”，打开路径为首页。
- R4. 朋友圈分享标题与转发标题保持一致，打开后进入首页。
- R5. 分享内容不得携带家庭名称、成员昵称、账目、事项、足迹或其他私人数据。
- R6. 未登录或没有家庭的接收者打开分享后，继续使用现有登录和首次使用流程，不新增绕过身份校验的入口。

## 成功标准

- 微信右上角菜单中的“转发”和“分享到朋友圈”不再置灰。
- 好友打开转发卡片后能进入小程序首页，并由现有流程决定后续去向。
- 分享卡片和朋友圈内容只包含公开品牌文案，不泄露家庭数据。

## 范围边界

- 本次只修复截图所示的首页分享能力，不改变邀请成员页的定向邀请分享。
- 本次不新增页面内分享按钮，不改变首页布局。
- 本次不为账本、足迹、事项等内容页生成带业务数据的分享卡片。
