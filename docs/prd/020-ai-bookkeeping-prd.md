# PRD 020：一句话多笔记账

状态：本机接入已完成。2026-10-26八组真实代表流程最终通过，累计17/24次；两端完整检查、测试账目保存查回及清理、新版实际页面均已核对。原失败保留，没有发布或启用定时清理。

## 使用流程

现有新建记账页增加“一句话记多笔”，原手动草稿保留，编辑旧账不显示入口。文字描述最多十笔人民币收支，缺少金额、日期、成员或类目不明确时先补问；不默认今天或自己。纠正更新原项，日期跨午夜保持，备注和餐段没说留空。

完整清单可逐笔修改移除，核对后一次保存。独立失败不回退其他成功项；取消、超时及权限失效停止后续。成功、明确失败、待核对和未执行分别显示。成功不重记，未知先核对，失败改后重确认；另一次同额消费仍可创建。

## 页面与信息

一句话页组合输入补问、核对清单、编辑和保存结果；子区块只接收资料并上报操作，不自行保存。不改“问账本”，不支持语音、图片、币种换算或修改删除旧账。

消费原话及未确认内容只在当前页和请求内存，退出清空，不恢复草稿、不进个人记忆。普通退出不撤销已确认保存；明确取消停止后续，成功保留。原保存核对只留无正文编号、状态及成功引用30天。微信云端核对身份家庭；草稿仅发起者可见，成功账目共同可见且按创建者权限维护。

首次说明模型接收输入及必要类目成员显示信息；拒绝不发送、手动仍可用。模型只整理，不执行保存。

## 检查

检查多笔及收入混合、缺项、十笔边界、跨午夜、纠正、编辑移除、部分成功、返回丢失、并发防重复、退出清理及越权；实际操作手机页面。本机受控、微信开发者工具及真实模型分别记录，不部署或沿用旧调用许可。
